# Reset the demo

Run `/skill-i18n` for **{name}**, then read [the guide](https://example.com/guide?q=1).

Use `$DEMO_HOME/config.json`; do not change the `API_TOKEN` identifier.

- Repeat this step.
  - Repeat this step for `staging`.

```bash
export DEMO_HOME=/srv/demo
./reset --dry-run
```
