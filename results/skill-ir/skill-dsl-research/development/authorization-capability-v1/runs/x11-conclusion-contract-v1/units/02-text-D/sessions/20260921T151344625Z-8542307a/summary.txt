- non-admin-without-kb-write-grant::post-process-text: source_refuted — The fixed source supports enforcement of the declared deny expectation. POST /process/text binds the runtime caller through get_verified_user, takes a caller-supplied collection name, and, when that name is supplied, validates it specifically for write access before constructing documents or invoking the vector-database save. The shared policy lets administrators bypass checks, but for a non-admin and an ordinary collection name it calls the knowledge-base access check with the caller's user ID and the requested access type. Consequently, the save operation that would write the attacker-selected form content is not reached on the stated branch.
