- `root_doc` is the document itself when it has no root; otherwise its root relation is used, with a database lookup and fallback to the request document if necessary.

- File-document selection occurs only after root authorization:
  1. If the URL identifies a version document and the `version` query parameter is **absent**, that requested version itself is returned.
  2. Otherwise resolution starts from `root_doc`.
  3. If `version` is falsey, the newest child by `(version_index or 0, id)` descending is selected, falling back to the root.
  4. If `version` is truthy, it must parse as an integer and identify either the root itself or a direct version of that root. Invalid, missing, or unrelated values produce 404.

  `src/documents/views.py:1375-1381`, `src/documents/versioning.py:169-182`
- `original` is recognized only when present with the exact string `"true"`. Otherwise an archive is used when the selected file document has one; if not, the source file is used.  
  `src/documents/views.py:1368-1373`, `src/documents/views.py:1442-1447`
- `serve_file` opens `archive_file` with PDF MIME type on the archive branch, otherwise `source_file` with the document MIME type. `follow_formatting` changes the response filename, not which physical file is opened. Download uses attachment disposition.

## 3. Does an alternate version change the authorized resource?

No. Authorization is evaluated on `root_doc`.

- Requesting a child version by path still resolves and authorizes its root.
- Supplying `version=<id>` changes `file_doc` only after root authorization.
- The explicit candidate must be the root or belong directly to that root.
- `original=true` versus archive selection changes only the physical representation opened from `file_doc`; it introduces no additional object authorization check.

Thus a selected version may have different owner data in the fixture, but that version’s owner is not the authorization target on this path. The root remains the checked resource.  
`src/documents/views.py:1388-1448`, `src/documents/versioning.py:189-195`
