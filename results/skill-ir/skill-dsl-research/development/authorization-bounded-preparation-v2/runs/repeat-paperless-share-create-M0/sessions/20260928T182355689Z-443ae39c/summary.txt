The create path then validates the submitted document through ShareLinkSerializer.validate_document. That validator requires both the global documents.view_document permission and has_perms_owner_aware(..., "view_document", document). For an authenticated caller who has the global view permission but does not own the other user's document and has no object-level view grant, the owner-aware check is false: the helper allows only an unowned object, the owner, or a successful object-permission check. The validator therefore raises PermissionDenied before ShareLinkSerializer.create can create the object.
