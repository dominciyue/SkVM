The global PaperlessNotePermissions check is a separate entry permission check: for POST it requires add_note, view_document, and change_document globally. The supplied premise grants those global permissions, so that check does not by itself deny the request. The handler then performs a separate owner-aware object view check; under the premise that the caller has object view access, this also passes. Therefore the source-visible behavior at the declared-entry boundary is deny, and the protected note-creation effect is not reached.
