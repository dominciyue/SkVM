## 1. 已完成的首个原型

普通 bare-agent 经真实派发边界运行显式 `--subworkflow`：每步执行本地命令并检查声明产物；失败时恢复该步输出，保留有效前缀；成功与失败都把结果交回模型，继续原任务。检查点进入 history、RunResult.steps 和 durable trace。旧整题 `replace` 保持兼容，新候选不因签名命中自动晋升。

[成功/故障示例](../../examples/tiered-solidification/README.md)实际操作本地文件，模型为脚本替身。107 项相关测试、354 项断言及类型检查通过。当前检查只覆盖文件/JSON 结构，参数显式或 regex 提取；没有真实模型收益、业务语义保证、自动类别/候选选择、跨会话恢复或远端效果回滚。

## 3. P0–P6：下一开发队列

执行顺序为 P0 → P1 → P2/P3 → P4 → P5 → P6。P2/P3 的实现可在接口明确后交错推进，实际模型运行保持统一计量。每项完成一次必要验证后向前，不以任务时长凑工。

### P0 分类和任务依据（建议 0.5–1 个工作日）

- [ ] 先重标已暴露 30 张任务卡中的不同结构：用途、候选边界、输入/产物来源、环境依赖、检查依据及恢复方式。混合和不明标签保留。
- [ ] 形成首批 4 个 skill、2 个用途类的开发池建议，每类 2 个；从公开包和已暴露材料选，避免只挑曾成功的包。补资料仅为缺失结构，不再无目的扩充语料。
- [ ] 每个任务登记原包版本/直接依赖、自然需求、输入来源、期望结果及独立评价。区分真实用户任务、研究者任务、合成输入；公共 skill 不等于真实用户需求。
- [ ] 原始输入、trace、编写/修订输入与评价输入分开。首个用户运行可供生成候选，效果测量必须包含随后变化输入。旧 held-out/Q1 不使用。

**产物与验收：** 一个结果根中的任务清单和分类表；所有标签均能指到说明或观察，评价范围不由候选作者决定。没有合适独立检查时保留未验证项或换另一任务结构，不伪造成功率。分类定义写回[分类页](classification-and-routing.md)，不新建分类白皮书。

### P1 实际观察与获准通道（建议 1–2 个工作日）

- [ ] 在工具执行后关联调用、退出、输出和文件变化。候选识别可看调用前结构，是否有效必须用执行后证据。一次成功记为一次观察，不冒充跨输入确定性。
- [ ] 为新模式补候选来源和证据记录，旧 JIT 保留为兼容基线。已有 `afterTool` 与 durable trace 复用，不再增加一套日志系统。
- [ ] 解开官方账号入口对授权 inquiry 的强绑定，向通用任务暴露同一子流程执行核心和状态交还。先定位真实 tool/turn 边界；官方 CLI 自己管理推理与历史，不能再套一个假 `LLMProvider` 循环。
- [ ] 在同一账号 harness 下验证 T0 和接续；记录实际工具、请求/回合、终态及 usage。裸账号能用但子流程 hooks 不可达时明确记未接通，不跨 harness 拼收益对照。

**失败测试：** 相似调用却执行失败不能提升候选；退出 0 但检查失败不能提升；真实结果关联到错误任务必须拒绝；host 执行不得伪装模型请求；接续不能重复派发已关闭或终态未知的账号请求。

**验收：** 一段普通本地子流程的成功和故障都能在获准模型通道接续，且账本可数清实际请求。账号不可用时继续离线责任，未运行行留下原因，第三方付费不替代。

### P2 候选生成与依赖（建议 1–2 个工作日）

- [ ] 复用已有 trace 提案/代码生成/包接口，优先使用 skill 自带脚本。候选由系统和模型从原运行提出，不由开发者为每个 skill 手工补成功程序。
- [ ] 将参数归为当前任务输入、前序输出、已声明常量、环境值或未知；一次样例里不变的数字不自动成为常量。依赖线索与已核实依赖分开。
- [ ] 从线性 trace 切出 T1 和相邻 T2，保留中间语义决定。模型只说明任务、边界与程序，不要求逐字段、多轮填完整解释表。
- [ ] 生成候选与对应局部检查，并用任务独立检查验证变化输入；手写参考候选仅作定位上限，单独计量。

**失败测试：** 示例路径硬编码、两个生产者同值导致误绑定、数字重复误认数据流、隐藏文件/随机种子依赖、重试噪声误当必要步骤。外部状态无法约束时缩小候选，余下工作继续模型。

**验收：** 至少两个不同结构的真实 trace 产生可采用候选，并在变化输入上实际执行；记录所有自动编写失败及修订，不能只交付手工参考稿。

### P3 路由、任务检查与有效状态（建议 1–2 个工作日）

- [ ] 透明规则选择 T0/T1/T2：类别给候选与验证器倾向，输入绑定、依赖和恢复覆盖决定可用性；成本未知时不默认合并到最大粒度。
- [ ] 验证器分结构、保存/完整性、独立计算/差分、语义评价；每份检查点说明已检查什么。类别只能选择已有检查能力，不能把“属该类”当作正确证明。
- [ ] 同一候选能在输入/环境变化时采用不同粒度；T0 正常继续。输出只包含路由理由、必要输入、有效产物与剩余责任，原始长日志按需读取。
- [ ] 失败时依赖表标出受影响数据。先保证线性前缀的保留和恢复；若已通过最终检查，不因随后非必要诊断失败强迫模型重做。

**失败测试：** 同名 skill 不同结构、不同名 skill 同结构；新增语义步骤必须缩小边界；结构通过而数字错误；失败覆盖了已验证文件；未声明修改使恢复保证失效；晚失败但任务已完成；模型恢复后仍不合格。类别与收益标签必须分开。

**验收：** 每个选择和恢复动作可由当前输入/观察解释；独立评价可识别“程序运行成功但任务错误”。保留固定粒度和去类别开关，供同候选消融。

### P4 小规模真实接线与修复（建议 0.5–1 个工作日）

- [ ] 使用 P0 的 4 个 skill，各选一个变化任务，对原流程/新流程配对：计划 8 次消费运行。原始 trace 获取与候选编写另计，不能藏在消费前。
- [ ] 在其中两个可恢复的本地案例上比较整段重做/有效状态继续：计划另 4 次故障恢复运行。故障注入仅对本地效果，两个条件用相同失败点。
- [ ] 每个案例验证产物和剩余自然任务，确认 helper 真执行、前缀未重做、最终交付合格。任一关键信息缺失时先修采集或接线，再判断质量。
- [ ] 发现共享缺陷当场暂停受影响的后续行、定向修复、保存原失败并做具名确认。两次同因修复仍无改善则停该责任，继续独立项。

**验收：** 四个 skill 的采用/拒绝/恢复都有终态与完整分母，自动来源与实际使用可追溯。小样本用于决定继续哪项机制，不宣称普遍质量非劣或稳定省 token。

### P5 分类与恢复的判决实验（规模在 P4 后确定）

- [ ] 目标覆盖 3 类、每类 2 个 skill，每个至少两个不同输入结构；至少两个来源谱系。完整包及现成脚本对所有适用条件可见，不拿刻意削弱的裸模型作唯一基线。
- [ ] 先比较原 SkVM 流程与自动策略，再在预先选定的小子集做下表消融。已有匹配行复用，避免为增加面板重复请求。
- [ ] 初期每个配对做两次、次序交错，给逐项结果；不足以判断波动时报告未定，再按预先写明的精度需求增加重复。不同版本修复分段报告。
- [ ] 检验 H1/H2/H3，依据见主文档。路由拟合和阈值调整只使用开发部分，确认任务按 skill/来源拆分；旧已暴露语料不称 unseen。

| 对照 | 共享部分 | 要回答的问题 |
|---|---|---|
| 原流程 / 现有 SkVM JIT / 新策略 | 模型、harness、skill、任务、工具与最终评价 | 整体增量是否超过现有基础；JIT 不适用也保留 |
| 固定 T1 / 固定 T2 / 新策略 | 候选程序池、输入、验证器和恢复 | 选择粒度是否有用；固定策略同样遵守适用条件 |
| 仅运行特征 / 类别＋特征 | 候选、验证器、训练数据和成本信息 | 类别标签本身是否有增量 |
| 重做 / 原样保留工作区 / 验证后保留 | 同一故障输入、候选、最终评价 | 哪种状态交还最可靠、省重复操作 |

**质量口径：** 全队列记录交付、硬约束、语义量表；按原需求登记非劣界限，关键内容/错误数字等不可用均值抵消。程序局部检查与最终评价独立。效率统计包括失败和恢复，成功行加速比只作附表。

**成本口径：** 真实模型调用、input/output/cache、工具/检查/恢复时长及首次编写成本分开；复用 1/5/10 次的累计成本与盈亏点给实测或明确估计。SDK 请求、账号回合与模型实际推理次数的不可观测部分分别说明，不用工具次数代替调用数。

### P6 判断与交付（建议 0.5 个工作日）

- [ ] 同时交付普通自然入口、一个可运行失败接续示例、分类/路由理由和必要回归；不要另建完整 CLI 或可视化平台。
- [ ] 按类别分别给出支持、取舍、负面或证据不足的结论。类别没有独立收益则保留为描述维度；状态接续有收益可单独成立。
- [ ] 若质量变差，定位验证遗漏还是路由/程序问题；若只有编写成本过高，给复用盈亏点；若每次消费都更贵，停止用更多重复运行期待摊销。
- [ ] 原件在一个主题结果根中分阶段保存，主文档只写结论和接口变化；不按每次修复新建 identity、任务书或长总结。

预计 P0–P4 需要约 4–8 个有效开发日，受账号与真实 skill 依赖影响；这是工作量估计，未承诺届时有正向研究结果。P5 在真实通道和独立评价可用后定规模，不边跑边无限扩样。
